# java-lotto-precourse

# 로또

## 🧩 기능 목록

### 1. 입력

- [x]  구입금액 입력
    - [x]  안내 문구 :  `구입금액을 입력해 주세요.`
    - [x]  공백인 경우 예외 발생

        `[ERROR] 입력값이 비어 있습니다.`

    - [x]  숫자가 아닌 경우, 0/음수/소수인 경우 예외 발생

        `[ERROR] 자연수를 입력해 주세요.`

    - [x]  1000으로 나누어 떨어지지 않는 경우 예외 발생

        `[ERROR] 구입 금액은 1000의 배수여야 합니다.`

  - [ ]  당첨 번호 입력
      - [ ]  안내문구 : `당첨 번호를 입력해 주세요.`
      - [ ]  쉼표(  `,`  ) 기준으로 분리한다.
      - [ ]  공백인 경우 예외 발생

         `[ERROR] 입력값이 비어 있습니다.`

      - [ ]  숫자가 아닌 경우 예외 발생

         `[ERROR] 자연수를 입력해 주세요.`

    - [x]  1 ~ 45 사이의 숫자가 아닌 경우 예외 발생

        `[ERROR] 1부터 45 사이의 숫자를 입력해주세요.`

    - [x]  6개의 숫자가 있지 않은 경우 예외 발생

        `[ERROR] 당첨 번호는 6개의 숫자여야 합니다.`

    - [x]  중복되는 숫자가 있는 경우 예외 발생

        `[ERROR] 당첨 번호는 1부터 45 사이의 중복되지 않는 6개의 숫자여야 합니다.`

      - [ ]  보너스 번호 입력
          - [ ]  안내문구 : `보너스 번호를 입력해 주세요.`
          - [ ]  공백인 경우 예외 발생

             `[ERROR] 입력값이 비어 있습니다.`

          - [ ]  숫자가 아닌 경우 예외 발생

             `[ERROR] 자연수를 입력해 주세요.`

    - [ ]  1 ~ 45 사이의 숫자가 아닌 경우 예외 발생

        `[ERROR] 1부터 45 사이의 숫자를 입력해주세요.`

    - [ ]  1개의 숫자가 아닌 경우 예외 발생

        `[ERROR] 보너스 번호는 1개의 숫자여야 합니다.`

    - [ ]  당첨 번호와 중복되는 경우 예외 발생

        `[ERROR] 보너스 번호는 당첨 번호와 중복되지 않아야 합니다.`

### 2. 로또 구매 및 로또 자동 발행

- [x]  구입 금액에 따른 로또 구입 개수 계산 : 구입 금액 / 1,000 (개)
    - [ ]  출력 문구 : `X개를 구매했습니다.`
- [x]  구입한 로또 개수만큼 1 ~ 45 사이의 중복되지 않는 숫자 6개 생성
- [ ]  구입한 로또 개수만큼 1 ~ 45 사이의 중복되지 않는 숫자 6개 랜덤 출력 (오름차순 정렬)
    - [ ]  출력 형식

    ```jsx
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    ```

### 3. 당첨 여부 확인

- [ ]  구매한 로또가 당첨 번호 6개와 몇 개 일치하는 지 확인
    - [ ]  5개가 일치한 경우에는 보너스 번호 일치 여부를 추가로 확인
- [ ]  위 결과에 따라 당첨 등수 결정
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
    - 그 외 : 낙첨 / 0원
- [ ]  당첨 등수의 개수를 누적하여 집계

### 4. 당첨 통계 출력

- [ ]  당첨된 로또 등수와 금액, 개수 출력
    - [ ]  출력 형식

          ```jsx
          당첨 통계
          ---
          3개 일치 (5,000원) - a개
          4개 일치 (50,000원) - b개
          5개 일치 (1,500,000원) - c개
          5개 일치, 보너스 볼 일치 (30,000,000원) - d개
          6개 일치 (2,000,000,000원) - e개
          ```

### 5. 총 수익률 계산

- [ ]  총 수익률 계산 : 당첨 금액 / 구입 금액 * 100 (%)
    - [ ]  당첨 금액 = ( 등수별 상금 x 개수 )의 총합
    - [ ]  BigDecimal 사용
    - [ ]  소수점 둘째 자리에서 반올림
- [ ]  출력 형식 : `총 수익률은 XX.X%입니다.`

### 6. 예외 처리

- [ ]  사용자가 잘못된 값을 입력할 경우`IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- [ ]  `Exception`이 아닌`IllegalArgumentException`,`IllegalStateException`등과 같은 명확한 유형을 처리한다.
