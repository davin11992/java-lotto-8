# java-lotto-precourse

# 🎰 로또

### 🧾 프로젝트 개요

이 프로젝트는 **로또 발행 및 당첨 결과 계산 로직**을 구현하는 프로그램입니다.

사용자는 구입 금액을 입력하면 자동으로 로또가 발행되며,
직접 입력한 **당첨 번호 및 보너스 번호**를 기준으로 **등수별 당첨 여부와 수익률**을 계산합니다.

### 🎮 실행 결과 예시

```jsx
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

### 🧱 프로그램 구조

```
lotto
 ├── Application.java                   // 프로그램의 진입점 (main)
 │
 ├── controller
 │    └── LottoController.java          // 전체 실행 흐름 제어 (입력 → 로또 발행 → 결과 계산 → 출력)
 │
 ├── model
 │    ├── domain
 │    │    ├── Lotto.java               // 로또번호(6개) 관리 및 유효성 검증
 │    │    ├── LottoMachine.java        // 입력된 금액에 따라 로또 자동 발행
 │    │    ├── LottoNumbersSet.java     // 로또번호(6개) + 보너스 번호를 함께 관리
 │    │    ├── Rank.java                // 당첨 등수 Enum (1~5등, 낙첨)
 │    │    └── Result.java              // 각 로또의 당첨 결과 계산 및 통계 데이터 저장
 │    │
 │    └── service
 │         └── ProfitCalculator.java    // 총 수익률 계산
 │
 ├── util
 │    ├── PurchaseAmountValidator.java  // 구입 금액 입력값 검증
 │    ├── WinningNumbersParser.java     // 문자열 형태의 당첨번호를 쉼표를 기준으로 List로 변환
 │    └── BonusNumberValidator.java     // 보너스 번호 유효성 검증
 │
 ├── common
 │    ├── LottoConstants.java           // 로또번호 범위, 가격 등 상수 정의
 │    └── ErrorMessage.java             // 공통 예외 메시지 상수 관리
 │
 └── view
      ├── InputView.java                // 사용자 입력 처리 (금액, 당첨번호 입력)
      └── OutputView.java               // 출력 처리 (구매 결과, 당첨 통계, 수익률)

```



## 🧩 기능 목록

### 1. 입력

- [x]  구입금액 입력
    - [x]  안내 문구 :  `구입금액을 입력해 주세요.`
    - [x]  공백인 경우 예외 발생

        `[ERROR] 입력값이 비어 있습니다.`

    - [x]  숫자가 아닌 경우, 0/음수/소수인 경우 예외 발생

        `[ERROR] 자연수를 입력해 주세요.`

    - [x]  1000으로 나누어 떨어지지 않는 경우 예외 발생

        `[ERROR] 구입 금액은 1000의 배수여야 합니다.`

  - [x]  당첨 번호 입력
      - [x]  안내문구 : `당첨 번호를 입력해 주세요.`
      - [x]  쉼표(  `,`  ) 기준으로 분리한다.
      - [x]  공백인 경우 예외 발생

         `[ERROR] 입력값이 비어 있습니다.`
      - [x]  쉼표로 구분하지 않은 경우 예외 발생
     
          `[ERROR] 쉼표(,)로 구분해야 합니다.`

      - [x]  숫자가 아닌 경우 예외 발생

         `[ERROR] 자연수를 입력해 주세요.`

    - [x]  1 ~ 45 사이의 숫자가 아닌 경우 예외 발생

        `[ERROR] 1부터 45 사이의 숫자를 입력해주세요.`

    - [x]  6개의 숫자가 있지 않은 경우 예외 발생

        `[ERROR] 당첨 번호는 6개의 숫자여야 합니다.`

    - [x]  중복되는 숫자가 있는 경우 예외 발생

        `[ERROR] 당첨 번호는 1부터 45 사이의 중복되지 않는 6개의 숫자여야 합니다.`

    - [x]  보너스 번호 입력
          - [x]  안내문구 : `보너스 번호를 입력해 주세요.`
          - [x]  공백인 경우 예외 발생

             `[ERROR] 입력값이 비어 있습니다.`

          - [x]  음수, 0, 소수인 경우 예외 발생

             `[ERROR] 1개의 자연수를 입력해 주세요.`

    - [x]  1 ~ 45 사이의 숫자가 아닌 경우 예외 발생

        `[ERROR] 1부터 45 사이의 숫자를 입력해주세요.`

    - [x]  1개의 숫자가 아닌 경우 예외 발생

        `[ERROR] 1개의 자연수를 입력해 주세요.`

    - [x]  당첨 번호와 중복되는 경우 예외 발생

        `[ERROR] 보너스 번호는 당첨 번호와 중복되지 않아야 합니다.`

### 2. 로또 구매 및 로또 자동 발행

- [x]  구입 금액에 따른 로또 구입 개수 계산 : 구입 금액 / 1,000 (개)
    - [x]  출력 문구 : `X개를 구매했습니다.`
- [x]  구입한 로또 개수만큼 1 ~ 45 사이의 중복되지 않는 숫자 6개 생성
- [x]  구입한 로또 개수만큼 1 ~ 45 사이의 중복되지 않는 숫자 6개 랜덤 출력 (오름차순 정렬)
    - [x]  출력 형식

    ```jsx
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    ```

### 3. 당첨 여부 확인

- [x]  구매한 로또가 당첨 번호 6개와 몇 개 일치하는 지 확인
    - [x]  5개가 일치한 경우에는 보너스 번호 일치 여부를 추가로 확인
- [x]  위 결과에 따라 당첨 등수 결정
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
    - 그 외 : 낙첨 / 0원
- [x]  당첨 등수의 개수를 누적하여 집계

### 4. 당첨 통계 출력

- [x]  당첨된 로또 등수와 금액, 개수 출력
    - [x]  출력 형식

          ```jsx
          당첨 통계
          ---
          3개 일치 (5,000원) - a개
          4개 일치 (50,000원) - b개
          5개 일치 (1,500,000원) - c개
          5개 일치, 보너스 볼 일치 (30,000,000원) - d개
          6개 일치 (2,000,000,000원) - e개
          ```

### 5. 총 수익률 계산

- [x]  총 수익률 계산 : 당첨 금액 / 구입 금액 * 100 (%)
    - [x]  당첨 금액 = ( 등수별 상금 x 개수 )의 총합
    - [x]  BigDecimal 사용
    - [x]  소수점 둘째 자리에서 반올림
- [x]  출력 형식 : `총 수익률은 XX.X%입니다.`

### 6. 예외 처리

- [x]  사용자가 잘못된 값을 입력할 경우`IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- [x]  `Exception`이 아닌`IllegalArgumentException`,`IllegalStateException`등과 같은 명확한 유형을 처리한다.
